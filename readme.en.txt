# NexaStore | Modern & Scalable E-Commerce Platform

**NexaStore** is a modern e-commerce platform designed to demonstrate real-world software engineering practices and scalable application architecture.

The project follows **Modular Monolith** architecture and **Clean Architecture** principles to ensure clear separation of concerns, maintainability, testability, and future scalability.

### Technology Stack

- **Backend:** .NET 10, ASP.NET Core Web API, C#
- **Frontend:** React, TypeScript, Tailwind CSS
- **Database:** PostgreSQL, Entity Framework Core
- **Caching:** Redis
- **Message Broker:** RabbitMQ
- **Containerization:** Docker, Docker Compose
- **Monitoring & Observability:** OpenTelemetry
- **Architecture:** Modular Monolith, Clean Architecture

### Key Technical Highlights

- Layered architecture with Domain, Application, Infrastructure, and API projects.
- Modular design for core business domains such as Catalog, Identity, Ordering, Inventory, and Payment.
- RESTful API development for frontend-backend communication.
- Relational data management using PostgreSQL and Entity Framework Core.
- Distributed caching strategies using Redis.
- Asynchronous messaging and background processing with RabbitMQ.
- Containerized development and deployment environments using Docker.
- Application monitoring and observability with OpenTelemetry.

**Project Objective:** To build a production-oriented e-commerce platform with a strong focus on clean architecture, maintainability, extensibility, performance, and modern backend engineering practices.
